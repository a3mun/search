# 🔍 Search of Sky — PWA

**جستجو در آسمون — نسخه‌ی وب (اندروید/موبایل)**

---

## 📖 معرفی

نسخه‌ی وب‌اپلیکیشن (PWA) از «جستجو در آسمون».
کاملاً آفلاین، نصب روی گوشی، بدون نیاز به نصب اپ.

---

## 🚀 نصب (بعد از آپلود روی GitHub Pages)

1. لینک رو توی Chrome گوشی باز کن:
   `https://sichooo.github.io/search-of-sky/`

2. منوی سه نقطه (بالا راست) → **Add to Home Screen**

3. اسم رو تأیید کن → **Add**

4. آیکون روی Home Screen اضافه می‌شه

5. از این به بعد، آفلاین کار می‌کنه

---

## 🎯 استفاده

1. **📂 پوشه** → پوشه‌ی دیتا رو انتخاب کن
2. عبارت جستجو رو تایپ کن
3. **جستجو** → نتایج نمایش داده می‌شن
4. کلیک روی هر نتیجه → متن کامل

---
